## 🛠️ Cara Menjalankan Project

### 1. Install Dependensi
Buka terminal di folder project ini, lalu jalankan:
```bash
npm install
```
*(atau gunakan `pnpm install` jika menggunakan pnpm)*

### 2. Jalankan Server Development
```bash
npm run dev
```
Buka browser di `http://localhost:3000` untuk melihat portofolio Anda secara langsung!

### 3. Build untuk Production
Untuk membuat file siap deploy (Vercel, Netlify, GitHub Pages, dll.):
```bash
npm run build
```
Hasil build akan tersimpan di folder `dist/`.
